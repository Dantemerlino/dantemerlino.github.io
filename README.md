# Dante Merlino — GitHub Pages CV

This repository hosts the public CV and one-page summary of Dante Merlino, MD, PhD —
head and neck surgical oncologist and Visiting Assistant Professor in the Department of
Otolaryngology–Head and Neck Surgery at the University of Illinois College of Medicine / UI Health,
Chicago.

**Live site:** [https://dantemerlino.github.io](https://dantemerlino.github.io)

---

### Files

| File | Purpose |
|---|---|
| `index.html` | Landing page: role, focus areas, selected work, and document links |
| `DanteMerlino_CV.pdf` | Full curriculum vitae |
| `DanteMerlino_Summary.pdf` | One-page condensed summary |
| `DanteMerlino.vcf` | Contact card (title, affiliation, and both email addresses) |
| `Headshot.jpg` | Portrait used in the page header |

### Updating

1. **Documents:** replace the PDFs with current versions, keeping the same filenames — the buttons on
   `index.html` link to these paths directly.
2. **Role or affiliation:** update `index.html` (the `<title>`, the `<meta name="description">`, and
   the header block) *and* `DanteMerlino.vcf` together, so the page and the contact card do not drift.
3. Commit and push to `main`; GitHub Pages redeploys automatically.

> Note: the profile README at [`Dantemerlino/Dantemerlino`](https://github.com/Dantemerlino/Dantemerlino)
> keeps its own copies of the CV and summary under different filenames (`Dante_Merlino_CV.pdf`,
> `Dante_Merlino_Summary.pdf`). Refresh both repositories when the CV changes.
